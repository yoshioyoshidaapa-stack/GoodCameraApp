# ゴキブリシューター MR（Meta Quest 向け）

自分の部屋の床にゴキブリが湧き出す、MR（パススルー）シューティングゲームです。
Quest のブラウザで開くだけで遊べます（インストール不要）。

## 遊び方

1. Quest のブラウザでこのフォルダの `index.html` を開く
2. 「MRで遊ぶ（部屋が見える）」を押す
3. コントローラーの引き金（トリガー）で撃つ

- 足元までたどり着かれる／顔に飛んでこられるとライフ（♥・3つだけ）が減る
- ねらいの輪を近づけるとゴキブリは逃げる
- 最初から飛ぶゴキブリが出る（羽音が立体音響で聞こえる）
- 2 WAVE ごとにボス「ゴキング」（子分を産む・10発以上必要）
- 連続で倒すとコンボ倍率（最大 x5）
- 左手コントローラーの上にスコア表示
- PC のブラウザでも「PCでお試し」でマウス操作で遊べる

## 仕組み

- WebXR（ブラウザでVR/MRを動かす仕組み）＋ three.js（`lib/` に同梱）
- ゴキブリの見た目・効果音はすべてプログラムで生成（画像・音声ファイルなし）
- 床の高さは Quest のガーディアン設定の床を使う

## 注意

- 部屋の形（壁・家具）は認識していないため、ゴキブリが家具の中から出てくることがあります
- 遊ぶときは周りに物がない、広めの場所で
