3Dプリント用 部品モデル(STL)  ※単位はすべて mm、原寸です

huskylens2_official.stl ... HuskyLens2。DFRobot 公式の3Dデータ(STEP)から変換。外形 70.4 x 58.5 x 24.2 mm (レンズの出っ張りを含む。仕様の「19mm」は本体のみ)
sg90_servo_approx.stl ..... SG90サーボの「見本」。公開されている一般的な寸法から作った近似。実物と違う可能性あり。
capacitor_16V1000uF_approx.stl ... 電解コンデンサの「見本」(直径10 x 高さ17 + 足8mm)。買った品の寸法に合わせて直す。
huskylens2_official.step ... 元の公式データ(CADソフト用)。
make_parts.py ... 見本を作るプログラム(数字を直して再実行すると作り直せる)。

未作成: ESP32基板、モバイルバッテリー、USB端子台、HuskyLens2の電源ボード
 → 寸法が見つからなかったため。実物の寸法(部品寸法メモのPDF)を測って送ってもらえれば作る。

使い方: STLを、車体を設計するソフト(Fusion、Tinkercad など)に読み込み、
 「部品が収まる穴・置き場」の型として使う。見本のSTLは、そのまま印刷しない(部品の代わりに置いて、収まりを見るためのもの)。
 3Dプリントの穴は、部品より 0.3〜0.5 mm 大きめにする。
