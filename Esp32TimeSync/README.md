# ESP32 時計合わせ（Esp32TimeSync）

Android スマホが、近くの ESP32 基板に、自動で今の時刻を送るアプリです。

- 基板側: `esp32/main.py`（MicroPython。BLE で時刻を受け取り、画面に時計を出す）
- スマホ側: `app/`（Android アプリ。基板を一度登録すると、基板が近くに来たら自動で時刻を送る）

## 状態

**まだ一度もビルド・実機確認をしていません。** 動かして、出た問題を直していく段階です。

## 使い方

### 1. 基板に書き込む（Mac）

`lcd.py` は、すでに基板に入っている前提です。

```bash
python3 -m mpremote connect /dev/cu.usbserial-8340 cp Esp32TimeSync/esp32/main.py :main.py
```

基板の EN ボタンを押すと、画面に「--:--:--」と赤い「NO SYNC」が出ます。これが「時刻を待っている」状態です。

### 2. アプリを入れる（Android Studio）

1. Android Studio で、この `Esp32TimeSync` フォルダを開く（GoodCameraApp ではありません）。
2. スマホを USB でつなぎ、実行ボタンを押す。

### 3. 基板を登録する（最初の1回だけ）

1. アプリを開き、「基板を登録する」を押す。
2. Bluetooth の許可を聞かれたら許可する。
3. 出てきた一覧から「ESP32CLK」を選ぶ。
4. 基板の画面が、時計に変われば成功。

### 4. 次から

基板の電源を入れて、スマホの近くに置くだけです。アプリを開く必要はありません。

## 分かっている弱点

- 基板の電源を一瞬だけ切って、すぐ入れ直した場合は、スマホが「基板が現れた」と気づかないことがあります。そのときはアプリの「今すぐ時刻を送る」を押してください。
- 電池の節約設定が強いスマホでは、裏での自動起動が止められることがあります。
- 時刻は、送った時点から基板が数えます。長く使うと、少しずつずれます。
